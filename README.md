# Hello from React

A basic React application that displays:

```text
Hello from React!
```

The project uses React and Vite.

## Requirements

- Node.js 18 or newer
- npm

## Install dependencies

```bash
npm install
```

## Run the development server

```bash
npm run dev
```

Open the URL displayed in the terminal. It is normally:

```text
http://localhost:5173
```

The development server listens on all interfaces, so another device can use the displayed Network URL when permitted by the host firewall.

## Create a production build

```bash
npm run build
```

The optimized application is generated in `dist/`.

## Preview the production build

```bash
npm run preview
```
